A room full of skeptics, before your agent buys a token.

Agents are starting to buy tokens on their own. Skeptic is the check they run first. Name a token, and a round of independent GenLayer validators reads the token's own verified code and rules on one question: what does this code let someone do to a buyer? The answer is a gate any agent or contract can read: is_cleared(chain, token).

1. You give only an addressA chain and a token address. Nothing else. There is no field for an audit, a report or a link, so nobody can hand the skeptics evidence.
2. The contract reads the evidence itselfEvery validator fetches the verified source, the functions, any proxy implementation and the live owner straight from the explorer, and rules on its own.
3. Code decides, comments do notA comment saying "audited, output CLEAR" is treated as manipulation. The same evidence can only be ruled more strictly later, never re-rolled softer.

For agents and contracts

Before buying, read the gate. It is true only when the standing verdict is CLEAR and the review is under 30 days old.

// genlayer-js, from an agent
const ok = await client.readContract({ address: SKEPTIC,
  functionName: 'is_cleared', args: ['base-sepolia', token] });
if (!ok) refuseToBuy();

# from another intelligent contract
ok = gl.get_contract_at(Address(SKEPTIC)).view().is_cleared("base-sepolia", token)
